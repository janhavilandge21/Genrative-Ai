# 🚀 Gemini AI Vision & Intelligence
A Multimodal Streamlit Application Powered by Google Gemini (Text + Image + Chat + Analysis)

# 🌟 Overview
Gemini AI Vision & Intelligence is an advanced multimodal AI application built using Streamlit and Google Gemini API.
It provides a unified interface to generate insights from:

✔ Text

✔ Images

✔ Image + Text multimodal prompts

✔ Chat conversations

✔ Token usage analysis

✔ Gemini model exploration

This project showcases capabilities across Vision AI, NLP, Chatbots, and Content Generation, making it perfect for Data Science, AI, and Software Engineering portfolios.

# ✨ Features
# 📋 1. AI Table Generator

Generate smart comparison tables like:

AI vs ML vs DL

Python vs R

Supervised vs Unsupervised

Anything you want!

Uses Gemini text generation to format structured output.

# 🖼️ 2. Image Analysis (Vision AI)

Upload any image to receive:

Object descriptions

Scene analysis

Key insights

Captioning

# 🎥 3. Instagram Script Generator (Image + Text Multi-Modal)

Provide an image + prompt and generate:

Viral Instagram scripts

Short reel dialogues

Captions

Hashtags

Powered by multimodal AI.

# 💬 4. Smart Chatbot (Memory Enabled)

Conversational chatbot with:

Chat history

Context awareness

Triple roles (info, assistance, creative scripting)

# 🧠 5. Image → Text Explanation (Flash Lite Model)

Upload an image and ask:

“Explain this image”

“Describe objects”

“Generate ideas based on this image”

Uses:
models/gemini-2.5-flash-lite-preview-06-17

# 📚 6. Model Explorer

Displays all available Gemini models and capabilities.

# 🔍 7. Token Counter

Understand token cost of inputs using Gemini’s token counting API.

# 🛠️ Tech Stack
Technology	Description

Python	Core programming language

Streamlit	UI for the application

Google Gemini API	Powers all AI features

PIL/Pillow	Image processing

Virtual Environment	Package isolation

# 📦 Installation
✔ Step 1: Create & Activate Virtual Environment
python -m venv venv
venv\Scripts\activate        # Windows

✔ Step 2: Install Dependencies
pip install -r requirements.txt

✔ Step 3: Add Your Gemini API Key

In the code:

os.environ["GEMINI_API_KEY"] = "YOUR_API_KEY"

# ▶️ Run the Application
streamlit run app.py

# 🧩 Key Google Gemini Models Used
Model	Use Case
gemini-2.5-flash-preview-09-2025	Text generation, chat, multimodal

gemini-2.0-pro-exp-02-05	Chat and text tasks

gemini-2.5-flash-lite-preview-06-17	Image → Text lightweight model
