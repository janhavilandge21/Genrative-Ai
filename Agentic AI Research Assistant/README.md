## 📌 Overview

This project is an **Agentic AI system** that performs multi-step reasoning to generate research reports.

Unlike traditional LLMs, this system can:
- Plan tasks
- Use tools
- Execute actions step-by-step

---

## 🎯 Features

✅ Multi-step reasoning  
✅ Task planning using LangGraph  
✅ Web search integration  
✅ Content summarization  
✅ Automated report generation  

---

## 🧠 Architecture

```

User Query → Planner → Tool Selection → Execution → Final Response

````

---

## 🛠 Tech Stack

- Python  
- LangGraph  
- LangChain  
- Groq LLM
